# Publikt API v1 – implementationsplan

> **För agenter:** Använd superpowers:subagent-driven-development (rekommenderas) eller superpowers:executing-plans för att genomföra planen uppgift för uppgift. Stegen har kryssrutor (`- [ ]`).

**Mål:** Ett versionerat, öppet JSON-API (`/api/v1/…`) med adressuppslag, sökning och källor, plus OpenAPI-fil och en guide som räcker för att bygga Home Assistant- och Homey-integrationer.

**Arkitektur:** Rena funktioner i `src/domain/` räknar bekvämlighetsfälten. En gemensam serverfunktion (`lookupAddress`) slår upp en adress oavsett källtyp och används av `v1`, `/api/schema` och ICS. `src/server/v1.ts` formaterar svaren, och tunna filer i `api/v1/` exponerar dem på Vercel.

**Teknik:** TypeScript, Vercel Functions (web-`fetch`-handlers), Vitest, Ajv 8 (dev-beroende, JSON Schema 2020-12) för kontraktstestet.

**Spec:** `docs/specs/2026-10-31-sopor-api-design.md`

## Globala krav

- Kod som funktionerna når (`api/`, `api/v1/`, `src/server/`, `src/domain/`, `src/sources/`, `src/data/street-index.ts`) har relativa importer med `.js` och aldrig `@/`.
- Datum är `YYYY-MM-DD`. "I dag" är `todayInStockholm(now)`. Aritmetik görs i `src/domain/dates.ts`.
- Dolda källor (`hidden: true`) syns aldrig. Utgå från `SOURCES`, aldrig `ALL_SOURCES`.
- Adress-id och ICS-UID ändras inte. API:t använder samma id som `/ics/<källa>/<id>.ics`.
- Varje `v1`-svar har `"apiVersion": "1"` och `Access-Control-Allow-Origin: *`.
- Fält utan värde skickas som `null` (`labels` som `{}`), aldrig utelämnade.
- Felkoder: `bad_request` (400), `not_found` (404), `source_unavailable` (502). Formen är `{ apiVersion, error: { code, message } }`.
- Commit-meddelanden på svenska, utan AI-attribution. Kör `npm run lint && npm test && npm run build` före varje commit.

## Fokus vid granskning

1. **Id med å/ä/ö eller procentkodning i sökvägen** (`/api/v1/adress/uppsala/%C3%B6stra-…`) ska avkodas exakt en gång, både via Vercels rewrite och i dev-routern. Test i uppgift 6.
2. **Adress utan kommande hämtningar** (allt i schemat har passerat): `next: []`, `summary: "Inga kommande hämtningar"`, status 200. Test i uppgift 3 och 6.
3. **Statisk källa vars datafil saknas eller ger 500** ska ge `source_unavailable` (502), inte 404 eller en krasch. Okänt id i en fungerande fil ger 404. Test i uppgift 5.
4. **Preview-adresser:** `url` och `links` ska peka på anropets egen origin, inte på produktion. Test i uppgift 6 och 7.
5. **Sökning med ort och komma** ("Storgatan 2, Uppsala") ska välja källor med gatuindexet som sajten gör. Test i uppgift 4 och 7.
